# Glamoo: Salon Booking App

A mobile web app (PWA-style) for a neighbourhood salon in Coimbatore, built for the E-Business Management course, Assignment 2.

**Student:** Harini Sri K A (24cb016), B.Tech CSBS, III Year
**Faculty:** Ms. S. R. Maheswari

## Features
- Catalogue and search: 16 services in 5 categories
- Booking: multi-service cart, stylist choice, date and time slots
- Checkout: UPI / card / pay at salon (simulated), coupons, loyalty points
- CRM: phone and OTP login (demo OTP: 1234), booking history, ratings, referral code
- Marketing and communication: offer banners, WhatsApp button, FAQ
- Operations: booking status tracking and an owner view with a sales summary

## Run it
Open `index.html` in a browser, or open the GitHub Pages link on a phone.

## Notes
Payments, OTP and messages are simulated. Data is stored in the browser (localStorage). No real card or personal data is collected.

Built with HTML, CSS and JavaScript only. Developed with the help of an AI assistant (Claude), reviewed and customised by the student.
